# AutoShiftMaker

自動でシフト表を作成するシンプルな Web アプリです。

## 使い方

1. `index.html` をブラウザで開く
2. 勤務体系（週の勤務回数・勤務時間）を登録する（不要な勤務体系は削除可能）
3. 勤務者名と勤務可能な勤務体系（複数選択可）を登録する（不要な勤務者は削除可能）
4. 対象月、時間ごとの必要人数、連続勤務日数上限を設定する
5. 「シフト表を作成」を押す

## 仕様

- 勤務体系は登録後に再利用できます（ブラウザの `localStorage` に保存）
- 勤務体系を削除すると、その勤務体系だけに紐づく勤務者は登録一覧から削除されます
- 夜勤（開始時刻 >= 終了時刻）の場合、`18日〜19日` の勤務後は `20日` を休みにします
- 条件を満たせない場合は失敗メッセージを表示します
