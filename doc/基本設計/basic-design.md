# AutoShiftMaker 基本設計書

## 1. システム構成
- `index.html`: 画面定義、入力UI、インライン初期化スクリプト。
- `app.js`: 画面イベント処理、入力検証、表示更新、状態管理。
- `scheduler.js`: シフト自動作成ロジック。

## 2. 画面設計
### 2.1 作成条件エリア
- 対象月入力。
- 連続勤務日数上限入力。

### 2.2 必要人数エリア
- 0〜23時の時間帯別人数入力。

### 2.3 勤務体系登録エリア
- 入力項目: 名称、週上限回数、開始時刻、終了時刻。
- 一覧表示: 勤務体系情報 + 削除ボタン。

### 2.4 勤務者登録エリア
- 入力項目: 勤務者名、勤務可能勤務体系（チェックボックス複数選択）。
- 一覧表示: 勤務者名 + 対応勤務体系 + 削除ボタン。

### 2.5 結果表示エリア
- 成功時: 日付・勤務者（勤務体系名付き）テーブル。
- 失敗時: エラーメッセージ。

## 3. データ設計
### 3.1 勤務体系
- `id`: 一意識別子。
- `name`: 勤務体系名。
- `maxPerWeek`: 週の上限回数。
- `startHour`: 開始時刻（0〜23）。
- `endHour`: 終了時刻（0〜23）。

### 3.2 勤務者
- `name`: 勤務者名。
- `patternIds`: 勤務可能な勤務体系ID配列。

### 3.3 シフト結果
- `success`: 成否フラグ。
- `month`: 対象月。
- `assignments[]`: 日別割当（`date`, `workers`, `shifts`）。

## 4. 永続化設計
- 保存先: `localStorage`
- キー: `autoshiftmaker.patterns`
- 対象: 勤務体系配列

## 5. バリデーション方針
- 勤務体系名、勤務者名は必須。
- 勤務体系の回数は1以上の整数。
- 勤務時間は0〜23の整数。
- 勤務者は勤務可能勤務体系を1件以上選択必須。
- 連続勤務日数は1以上の整数。
- 必要人数は0以上の整数。

## 6. 例外・エラー時挙動
- 入力不正時は作成処理を中断し、エラー表示。
- シフト生成不能時は失敗メッセージ表示。
